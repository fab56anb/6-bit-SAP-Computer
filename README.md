## Overview

This project presents the design and simulation of a **6-bit computer based on the SAP-1 (Simple-As-Possible) architecture**.

The computer was developed as an academic project at the **Islamic University of Technology (IUT)** to demonstrate fundamental concepts of digital logic, computer organization, and processor operation.

The complete digital circuit was designed and simulated using **Proteus Design Suite**.

## Objectives

* Design a functional 6-bit computer based on the SAP-1 architecture.
* Understand the fundamental principles of computer organization and processor operation.
* Implement the datapath and control mechanisms required for instruction execution.
* Demonstrate data transfer and processing at the hardware level.
* Simulate and verify the designed computer using Proteus.

## Architecture

The project follows the basic principles of the **SAP-1 architecture**, where instructions and data are processed through a common datapath under the control of a control unit.

The 6-bit implementation demonstrates the interaction between the computer's memory, registers, arithmetic and logic operations, and control signals during instruction execution.

## Design & Simulation

The complete circuit was designed and simulated using **Proteus Design Suite**.

The repository contains the Proteus project file used to implement and simulate the 6-bit SAP computer.
